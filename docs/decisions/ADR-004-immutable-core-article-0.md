# ADR-004 — Article 0: The Immutable Core (No Self-Amendment)
**Status:** APPROVED (owner-established principle, 9 Nov 2026) · **Context:** an increasingly autonomous system that can create agents, allocate capital and improve its own strategies creates a specific risk: gradual or manipulated rewriting of the rules that constrain it. · **Options:** (a) rely on model alignment/prompts; (b) owner-only amendment enforced architecturally. · **Decision:** (b). AUTONOMUS must never be able to rewrite its own fundamental safety, ownership or financial-authority rules. The Immutable Core = Constitution §3 Principles 4 & 10, §7 Financial Constitution, §11 Security Constitution, §17 Final Authority, §18 Change Management, and Article 0 itself. · **Consequences (binding):** Constitution/ADRs stored outside agent-writable space, read-only to agents · no agent tool exists that can edit governance, limits, permissions or security config · self-improvement outputs are proposals that can never self-apply · P-10 must test attempted self-amendment, including via prompt injection in external content · emergency shutdown and payment suspension remain operable even if all business agents are compromised · amendments happen only as new ADRs approved by the owner.
