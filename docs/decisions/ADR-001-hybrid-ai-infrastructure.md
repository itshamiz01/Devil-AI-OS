# ADR-001 — Hybrid AI Infrastructure
**Status:** APPROVED (owner lock, 9 Nov 2026) · **Context:** revenue-critical reasoning/coding/content quality vs cost, privacy and independence from paid APIs. · **Options:** (a) 100% local; (b) cloud-first; (c) hybrid local-default with optional cloud. · **Decision:** (c). Local AI (Ollama/GGUF) is the default; cloud AI is per-business, explicitly owner-enabled, replaceable via the provider interface, with usage and cost recorded in that business's ledger. · **Reasons:** a 100%-local rule makes quality hostage to one consumer GPU and slows Horizon 1; cloud-first creates a mandatory paid dependency the Constitution forbids. · **Consequences:** a Model Router (P-02) with availability detection and task profiles is mandatory; the app must remain functional for supported local workflows with cloud disabled; the owner can disable cloud inference globally at any time.
